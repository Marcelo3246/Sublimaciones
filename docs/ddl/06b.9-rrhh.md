# 06b.9 rrhh

DDL del esquema `rrhh`. Solo el **catálogo de personal** (fase 1). La nómina (configuración de comisiones, periodos de planilla, comisiones acumuladas, adelantos, liquidación y pagos) queda **diferida** — ver [09 Decisiones diferidas y fases](../09-decisiones-diferidas-y-fases.md).

Referencia de revisión del modelo de [06.9 rrhh](../modelo-datos/06.9-rrhh.md).

```sql
CREATE SCHEMA IF NOT EXISTS rrhh;

CREATE TABLE rrhh.trabajador (
    id              BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    nombre_completo VARCHAR(150) NOT NULL,
    cargo           VARCHAR(50) NOT NULL,    -- impresor, vendedor, disenador, planchador, confeccionador...
    telefono        VARCHAR(30),
    correo          VARCHAR(150),
    fecha_ingreso   DATE NOT NULL DEFAULT CURRENT_DATE,
    usuario_id      BIGINT,                  -- referencia debil a nucleo.usuario si tiene login
    is_active       BOOLEAN NOT NULL DEFAULT true,
    creado_en       TIMESTAMPTZ NOT NULL DEFAULT now(),
    actualizado_en  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_trabajador_cargo ON rrhh.trabajador (cargo) WHERE is_active;

CREATE TABLE rrhh.trabajador_local (
    id            BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    trabajador_id BIGINT NOT NULL REFERENCES rrhh.trabajador(id),
    local_id      BIGINT NOT NULL REFERENCES nucleo.local(id),
    is_principal  BOOLEAN NOT NULL DEFAULT false,
    CONSTRAINT trabajador_local_uk UNIQUE (trabajador_id, local_id)
);
-- Solo un local principal por trabajador
CREATE UNIQUE INDEX idx_trabajador_local_principal ON rrhh.trabajador_local (trabajador_id)
    WHERE is_principal;
```
