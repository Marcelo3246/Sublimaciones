# 06.11 reports

El módulo `reports` **no crea tablas propias de negocio**: solo consulta los otros esquemas. Es el único módulo sin DDL.

## Qué agrega

| Reporte | Se calcula sobre |
| --- | --- |
| Ventas por local y periodo | `ventas.pedido_venta`, `ventas.factura` |
| Pedidos en producción | `ventas.pedido_venta` por estado |
| Stock crítico | `inventario.stock` contra `inventario.nivel_minimo` |
| Comparativa de proveedores | `compras.historial_precio_proveedor` |
| Giro de inventario | `inventario.movimiento_stock` |
| Desempeño de producción por máquina | `produccion.operacion_maquina` |
| Comisiones por pagar | **Diferido a fase 4** con la nómina |

El dashboard (RF-56) y los reportes (RF-57) son agregaciones; la exportación a CSV/PDF y la impresión desde el navegador (RF-58) las resuelve el frontend.

## Regla

Si un reporte necesita un snapshot histórico puntual, se agrega su **tabla explícita** en [06 Modelo de datos](../06-modelo-de-datos.md), nunca una vista enlazada físicamente a otro módulo.
